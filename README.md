# Бот записи к психологу

Проверка Timepad запускается в GitHub Actions около 09:07 и 21:07 МСК и по запросу `/check` в Telegram. Если Timepad не отвечает серверу GitHub напрямую, используется переведённое представление Яндекса. Результат передаётся в Google Apps Script, который хранит подписчиков и отправляет уведомления.

В личном чате с [ботом](https://t.me/cu_wellbeing_slots_bot):

- `/start` — подписаться и сразу получить последний сохранённый список;
- `/check` — сразу получить последний список и запустить свежую проверку; после её завершения придёт результат;
- `/stop` — отписаться.

В сообщениях время сгруппировано по дате. Бот доступен любому пользователю, начавшему личный чат командой `/start`. Календари пользователей не используются.

Исходный код облачной проверки: `check.py`. Telegram webhook и хранение подписчиков: Google Apps Script. Ключи находятся в секретах GitHub Actions и свойствах скрипта, в репозитории их нет.
