# Проверка записи к психологу

GitHub Actions запускает проверку Timepad дважды в сутки: около 09:07 и 21:07 МСК. Если доступные слоты изменились, бот отправляет полный список в Telegram. Сверка с календарями отключена. Ручной запуск доступен на вкладке Actions → Check psychologist appointments → Run workflow.

Репозиторий содержит только открытый код и техническое состояние последней проверки. Токен бота и ID чата находятся в GitHub Actions Secrets (`BOT_TOKEN`, `CHAT_ID`).

GitHub иногда задерживает запланированные задания. Если сайт Timepad не отвечает с серверов GitHub, задание сообщит об ошибке, но слоты нельзя будет считать проверенными.
