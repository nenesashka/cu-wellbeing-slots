# CU CareSlot

Телеграм-бот [@cucareslot_app](https://t.me/cucareslot_app) следит за записью к двум психологам ЦУ:

| Психолог | Формат | Страница записи |
| --- | --- | --- |
| Светлана Шутькова | очно, кабинет 406 | https://cu-events.timepad.ru/event/3219855/ |
| Лилия Павлова | онлайн | https://cu-events.timepad.ru/event/3558805/ |

GitHub Actions запрашивает проверку обеих страниц примерно в 09:07 и 21:07 МСК. Запуск по расписанию может опаздывать на стороне GitHub. Если доступность изменилась, подписчик с `PRIORITY_CHAT_ID` получает сообщение первым. Для остальных подписчиков та же рассылка запускается не раньше чем через час после успешной отправки приоритетного сообщения. Владелец привязывает личный чат однократной командой `/priority <код>`; в репозитории хранится только SHA-256 кода. Пока приоритетный чат не привязан или первое сообщение ему не доставлено, общая рассылка не отправляется. Команда `/check` запускает дополнительную проверку и обновляет ответ только запросившему пользователю; остальные подписчики не получают уведомление из-за чужого запроса. В период задержки другие пользователи могут увидеть новые слоты через собственную команду `/check` или напрямую на открытой странице Timepad: приоритет относится только к рассылке. Проверки двух страниц идут параллельно. Если один источник недоступен, другой продолжает обновляться, а бот явно помечает ошибку. Устаревшие слоты при ошибке не показываются как актуальные.

Telegram webhook и список подписчиков работают в Google Apps Script. Код вебхука хранится в [`appsscript/Code.gs`](appsscript/Code.gs). Чувствительные ключи хранятся только в секретах GitHub Actions и свойствах скрипта. Mac пользователя не участвует в работе бота; календарные подписки не используются.

## Команды

- `/start` — включить уведомления и показать оба направления;
- `/check` — показать последние данные и запустить свежую проверку;
- `/svetlana` — слоты очной консультации;
- `/lilia` — слоты онлайн консультации;
- `/help` — помощь;
- `/stop` — отключить уведомления.

Владелец может отправить скрытую команду `/stats`, чтобы открыть личную панель разработчика. Кнопки в том же сообщении переключают сводку, проверки, ошибки, доставку, последние облачные запуски и страницы пользователей. Доступ проверяется по привязанному приоритетному чату; другим пользователям статистика и юзернеймы недоступны.

Панель показывает активные подписки, известных боту пользователей, явно отключивших уведомления, ручные запросы и завершённые проверки за сегодня и с начала учёта, время работы проверки, ожидание запуска по расписанию, время ответа на ручной запрос, ответы Telegram, ошибки источников и доставки, последние сообщения владельцу и общую рассылку. Юзернеймы сохраняются только после обращения пользователя к боту и только когда Telegram их передаёт. Существовавшие до панели подписки входят в общий счётчик, но их прошлые действия, ошибки и юзернеймы не восстанавливаются. Пользователь, который вызывает только `/check`, учитывается как известный чат без подписки.

Под сообщениями есть кнопки обновления, перехода на страницы Timepad и справки. Справка открывается в том же сообщении и содержит кнопку возврата к слотам. Новые сообщения приходят при изменении слотов по расписанию. Время в сообщениях — московское.

Рассылка изменений отправляется параллельными порциями до 12 адресатов с паузой между порциями. Это удерживает бесплатную рассылку в пределах Telegram и позволяет обслужить сотни подписчиков в рамках одного запуска Apps Script. Проверка на 700 адресатов есть в тестах; реальные тестовые сообщения пользователям не отправляются.

## Проверка кода

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node tests/test_apps_script.js
```

Публикация `appsscript/Code.gs` требует создания новой версии развёртывания веб-приложения. Обновление кода без новой версии не меняет рабочий webhook. После публикации нужно вызвать `configureBotProfile()` для обновления списка команд и текста профиля.
