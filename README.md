# CU CareSlot

Телеграм-бот [@cucareslot_app](https://t.me/cucareslot_app) следит за записью к двум психологам ЦУ:

| Психолог | Формат | Страница записи |
| --- | --- | --- |
| Светлана Шутькова | очно, кабинет 406 | https://cu-events.timepad.ru/event/3219855/ |
| Лилия Павлова | онлайн | https://cu-events.timepad.ru/event/3558805/ |

GitHub Actions проверяет обе страницы примерно в 09:07 и 21:07 МСК. Команда `/check` запускает дополнительную проверку: бот сразу показывает последние полученные данные, а затем сообщает результат свежей проверки. Проверки двух страниц идут параллельно. Если один источник недоступен, другой продолжает обновляться, а бот явно помечает ошибку. Устаревшие слоты при ошибке не показываются как актуальные.

Telegram webhook и список подписчиков работают в Google Apps Script. Код вебхука хранится в [`appsscript/Code.gs`](appsscript/Code.gs). Чувствительные ключи хранятся только в секретах GitHub Actions и свойствах скрипта. Mac пользователя не участвует в работе бота; календарные подписки не используются.

## Команды

- `/start` — включить уведомления и показать оба направления;
- `/check` — показать последние данные и запустить свежую проверку;
- `/svetlana` — слоты очной консультации;
- `/lilia` — слоты онлайн консультации;
- `/help` — помощь;
- `/stop` — отключить уведомления.

Под сообщениями есть кнопки проверки, выбора психолога и перехода на Timepad для записи. Кнопки выбора и проверки редактируют текущее сообщение; новые сообщения приходят при изменении слотов по расписанию. Время в сообщениях — московское.

## Проверка кода

```sh
python3 -m unittest discover -s tests -p 'test_*.py'
node tests/test_apps_script.js
```

Публикация `appsscript/Code.gs` требует создания новой версии развёртывания веб-приложения. Обновление кода без новой версии не меняет рабочий webhook. После публикации нужно вызвать `configureBotProfile()` для обновления списка команд и текста профиля.
