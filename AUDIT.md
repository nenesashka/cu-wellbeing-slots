# Аудит CU CareSlot — 25 октября 2026

## Что проверено и исправлено

- **Два источника.** Светлана Шутькова (очно, событие 3219855) и Лилия Павлова (онлайн, событие 3558805) проверяются параллельно. В сообщениях и кнопках они разделены.
- **Доступность слотов.** Для повторяющихся событий Timepad общий `reg_open=false` может соседствовать с доступными дочерними слотами. У Лилии доступные онлайн-слоты имеют `tickets_limited=false` и пустое `tickets_left`. Приоритет отдан состоянию конкретного времени; отсутствие лимита не считается отсутствием мест. Это проверено на реальных страницах обоих психологов.
- **Частичный сбой.** Ошибка одной страницы не стирает данные другой. Неактуальные данные не выдаются за текущие.
- **Повторы.** Telegram update ID и время результата облачной проверки защищают от повторной обработки. При `/check` сначала приходит быстрый сохранённый список, а если изменений нет — только короткое подтверждение.
- **Интерфейс.** Есть команды `/start`, `/check`, `/svetlana`, `/lilia`, `/help`, `/stop`, кнопки проверки, выбора психолога и перехода на страницы Timepad. Кнопки навигации и проверки редактируют исходное сообщение. Время сгруппировано по датам и показано по Москве.
- **Скорость.** Два события проверяются одновременно; прямой запрос ограничен 12 секундами, затем используется резервное представление с лимитом 35 секунд. Быстрый ответ на `/check` берётся из последнего сохранённого результата.
- **Безопасность.** Ключи и токены не находятся в текущем репозитории и его истории. Обработчик принимает только личные чаты, проверяет секретный ключ вебхука и формат результата. Календарные ссылки пользователя не используются. Ранее присланный в переписке токен бота рекомендуется перевыпустить через BotFather.

## Практические ограничения

GitHub Actions запускается по расписанию приблизительно, поэтому уведомление о новом слоте не гарантируется в точную минуту. Timepad может ограничить прямой доступ облачным серверам; резервный источник помогает, но при недоступности обоих источников бот показывает ошибку соответствующего психолога вместо неподтверждённых слотов.
